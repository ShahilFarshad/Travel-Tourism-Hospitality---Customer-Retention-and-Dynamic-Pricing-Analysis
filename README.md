# Travel-Tourism-Hospitality-Customer-Retention-and-Dynamic-Pricing-Analysis

## Project Overview

This project focuses on analyzing hotel booking data using Exploratory Data Analysis (EDA) and Machine Learning techniques.

The main goal of the project is to:

- Analyze customer booking behavior
- Understand cancellation patterns
- Study pricing trends using ADR (Average Daily Rate)
- Build a machine learning model for booking cancellation prediction
- Generate business insights for customer retention and dynamic pricing strategies

The project was developed using Python, Google Colab, Pandas, Matplotlib, Seaborn, and Scikit-learn.

## Objectives

- Perform Exploratory Data Analysis (EDA)
- Understand hotel booking trends
- Analyze customer cancellation behavior
- Study seasonal booking patterns
- Create useful visualizations and graphs
- Build a Logistic Regression Machine Learning model
- Predict booking cancellations
- Generate insights for hotel business improvement

## Machine Learning Model

A Logistic Regression model was used to predict hotel booking cancellations.

### Features Used
- lead_time
- adr
- adults
- total_stay

### Target Variable
- is_canceled

### Model Process
- Data selection
- Train-test split
- Model training
- Prediction
- Performance evaluation

### Evaluation Methods
- Accuracy Score
- Classification Report
- Confusion Matrix

The model helped identify booking cancellation patterns and customer behavior.

## Business Insights

Important insights discovered from the analysis:

- Most bookings were not canceled.
- City hotels received more bookings.
- Higher ADR values showed higher cancellation chances.
- Most customers booked with shorter lead times.
- Seasonal booking trends were observed.
- Most customers made fewer special requests.

These insights can help hotels improve pricing and customer retention strategies.
